# 《马拉松王子》资料站

一个专门介绍 2011 年国产运动奇幻动画《马拉松王子》（Prince Marathon）的网站：剧情与世界观、七位主要角色、全 52 集目录、幕后制作、动画音乐、播出与评价、资料来源，共 9 个页面（含 404 页）。

**纯静态、零依赖、无后端**：构建产物 `dist/` 可以直接放到任何静态托管上。

---

## 一、现在就能看

仓库自带一个零依赖静态服务器，已经在跑：

```bash
node serve.mjs                              # 默认 0.0.0.0:8788，服务 dist/
node serve.mjs --port 9000                  # 换端口
node serve.mjs --root dist-standalone       # 服务离线单文件版
node serve.mjs --host 127.0.0.1             # 只允许本机访问
```

启动后终端会打印两个地址：

| 地址 | 谁能打开 |
| --- | --- |
| `http://127.0.0.1:8788/` | 本机 |
| `http://<本机内网IP>:8788/` | 同一局域网 / WiFi 下的任何人（本次启动时为 `http://10.40.86.168:8788/`，IP 随网络变化） |

同一局域网的人打不开时，通常是 Windows 防火墙拦了 Node 入站连接，管理员权限执行一次即可放行：

```powershell
New-NetFirewallRule -DisplayName "马拉松王子资料站 8788" -Direction Inbound -Protocol TCP -LocalPort 8788 -Action Allow
```

`0.0.0.0` 只对本机所在局域网可见，不会暴露到公网。要公网地址请看 **[DEPLOY.md](DEPLOY.md)** —— GitHub Pages 工作流、Netlify / Vercel / Cloudflare Pages 配置都已经写在仓库里，导入即可发布。

## 二、三种交付形态

| 形态 | 位置 | 用途 |
| --- | --- | --- |
| 可部署站点 | `dist/` | 标准静态站点（页面 + `assets/`），扔到任何静态托管即可 |
| 离线单文件版 | `dist-standalone/` | CSS / JS / 插画全部内联，9 个**完全自包含**的 HTML，双击即看，可直接微信或邮件发送 |
| 压缩包 | `marathon-prince-dist.zip`（78 KB）· `marathon-prince-standalone.zip`（144 KB） | 前者可直接拖进 Netlify Drop 发布；后者适合当附件发人 |

## 三、目录结构

```
marathon-prince/
├── src/
│   ├── style.css          手写样式（配色取自厦门海蓝、马拉松圣火橙金、修罗紫、龙族朱红）
│   └── site.js            手写交互：导航高亮、滚动进场、分集搜索筛选、集号跳转
├── build.mjs              站点生成器：数据 + 模板 + 全部页面文案（唯一编辑入口）
├── art.mjs                自绘 SVG 美术：首屏厦门赛道插画、海报、标识、角色徽章、赛道分隔带
├── serve.mjs              零依赖静态服务器（MIME、ETag、缓存、404、路径穿越防护、HEAD）
├── check.mjs              冒烟测试：链接、资源、标签平衡、关键内容、单文件版内联情况
├── qa-slice.mjs           开发工具：把单个 section 拆成独立页面，便于逐块截图验收
├── shots.ps1              开发工具：批量无头截图（Chrome/Edge）
├── DEPLOY.md              部署与分享指南（局域网 / 公网 / 离线三种方式）
├── netlify.toml · vercel.json · .github/workflows/deploy-pages.yml
├── dist/                  【构建产物】可部署站点
└── dist-standalone/       【构建产物】离线单文件版
```

## 四、构建与自检

```bash
node build.mjs     # 产出 dist/ 与 dist-standalone/
node check.mjs     # 自检：链接、资源、标签平衡、关键内容、单文件版是否真的自包含
```

所有文案与数据都集中在 `build.mjs` 顶部的常量里（`INFO`、`CHARACTERS`、`EPISODES`、`STAFF`、`MUSIC`、`BROADCAST`、`AWARDS`、`RECEPTION`、`SOURCES` 等），改数据即改站点。设置站点根地址可生成 canonical 链接与 sitemap：

```bash
SITE_URL=https://example.com/marathon-prince node build.mjs
```

## 五、内容与核查原则

本站对每条事实标注来源，遇到来源互相矛盾时**并列列出并说明核查过程**，不做单方面裁定。较重要的几处结论：

| 事项 | 结论 |
| --- | --- |
| 集数 | 52 集。哔哩哔哩页面显示“全 44 话”，但番剧接口实际返回 `ep94742–94793` 共 52 条剧集，属平台元数据错误 |
| 单集片长 | 央视网 13 分钟、制作方 12 分钟、百度百科 11 分钟；B 站实测 10:02–13:07。搜狗/360 百科的 23 分钟可排除 |
| 获奖 | 唯一能在官方文件中核实的奖项是 **2011 年度少儿精品及国产动画发展专项资金“优秀国产动画片”三等奖、15 万元**（2012-04-26 公布）。流传更广的“2010 年广电总局第一批优秀国产动画片推荐”，经逐条比对广电总局 2010 年四批名单，**均无本片** |
| 评分 | 豆瓣 5.3 / 10，哔哩哔哩 9.4 / 10（378 人评）。差距来自“评价作品”与“重温童年”两种观看前提 |
| “抄袭《海贼王》”争议 | 第 13–14 集确有角色扮演其他动漫人物的桥段；制作方 2017-06-05 发《怒怼毒舌电影声明》解释为致敬/异装马拉松；指控依据停留在“名字相近 + 一件红褂子草帽 + 客串乱入”。本站不把该片标注为抄袭作品 |
| 厦门国际马拉松代言 | 央视网原文是“**有望**成为……动漫形象代言人”，未找到任何后续官方公告，不能写成“已成为” |

## 六、关于抓取方式（重要）

任务要求使用 Firecrawl 抓取资料，但**当前环境没有配置 Firecrawl**：既没有挂载 Firecrawl 的 MCP 工具，也没有 CLI 或 API Key。因此实际使用的是内置联网检索能力（网页搜索 + 逐页抓取原页），必要时直接调用平台公开接口获取结构化数据（哔哩哔哩番剧接口、豆瓣站内接口），再人工交叉核对。

此外，本机命令行无法访问外网（TLS 凭据受沙箱限制），所以海报、角色图等图片无法下载；站内所有视觉元素均为**程序化生成的 SVG 示意插画**，不含任何外部图片素材，也规避了版权风险。

## 七、已知信息缺口

- 中文维基百科条目：本机网络完全不可达（含镜像与 REST API），内容未取到。
- 豆瓣条目页/讨论页/短评页：被反爬重定向至验证页；评分与一条热门短评经站内接口取得，讨论帖正文未取到。
- 哔哩哔哩专栏 `cv30821879`、`cv33779698`：已改版为 opus 并要求验证码，正文未核对，站内未引用其原句。
- Bangumi：网络不可达，无法确认条目与评分。
- 金鹰卡通及地方台重播、CCTV-14 后续重播、腾讯视频与爱奇艺国内站上线情况：均未取到证据。
- 第 2–4 集等分集剧情：公开百科统一标注“暂无”，全 52 集里只有第 1 集与第 5 集有成文剧情。
