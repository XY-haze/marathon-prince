抓取方法与局限

这次是怎么抓的

按需求应以 Firecrawl 完成抓取，但当前会话没有配置 Firecrawl：既没有挂载 Firecrawl 的 MCP 工具，环境里也没有 CLI 或 API Key。因此实际使用的是内置联网检索能力（网页搜索 + 逐页抓取原页），必要时直接调取平台公开接口取结构化数据，再人工交叉核对。

图片为什么都是画的

本机命令行无法访问外网（TLS 凭据被沙箱限制），无法下载海报与角色图；同时为规避版权风险，站内页面、海报、角色徽章、赛道分隔带等全部视觉元素都是用 SVG 现场生成的示意插画，没有任何外部图片素材。

最有价值的一次核查

“2010 年获广电总局第一批优秀国产动画片推荐”这个说法流传很广，包括百科与制作方官网。为了验证它，本次调取了广电总局 2010 年四个批次推荐通知的原文逐条比对，四份名单里都没有本片；真正有官方文件的是 2011 年度专项资金的“优秀国产动画片三等奖、15 万元”以及获奖单位“福建厦门音像出版有限公司”。这类“来源很多但依据为零”的说法，是整理老动画资料时最常见的坑。
